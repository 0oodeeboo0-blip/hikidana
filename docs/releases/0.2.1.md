## Hikidana 0.2.1

コピーしたものやスクリーンショットを、画面の端の「引き棚」にしまっておける Windows 用のアプリです。

### 0.2.1 での直し

- まとめて貼るために選んだカードが、マウスを乗せても選んだ色のままになるようにしました。
- 起動したときの知らせが、まれに白いまま（文字が出ない）になることがあったのを直しました。

### できること

- **棚**: 画面の端の細い取っ手をクリックするか、**Win+Alt+V** で開きます。カードをクリックすると、作業中のアプリ（ChatGPT や Claude など）に貼り付けます。スクリーンショットは画像のまま貼れます。
- **閉じ方**: 棚の外をどこかクリックするか、Esc で閉じます。
- **まとめて貼る**: Ctrl を押しながらカードをクリックして選び、「まとめて貼り付け」で選んだ順に続けて貼ります。
- **ドラッグ**: カードをほかのアプリへドラッグして渡せます。ほかのアプリから取っ手や棚へドラッグすると、しまえます。
- **検索と絞り込み**、ピン留め、右クリックのメニュー（書式なしで貼る・名前を付けて保存など）。
- **片付け**: 「…」の「ピン留め以外のスクリーンショットを消す」、設定の「古いものを自動で消す」。
- **設定**: 棚の位置（右・左・上・下、モニター）、開き方、ショートカットキー、色（ライト・ダーク）、しまっておく数、Windows にサインインしたら起動、など。
- **新しい版のお知らせ**: 新しい版が出ると知らせて、ボタン 1 つで入れ替えます（棚の中身と設定はそのままです）。

## 使い方

1. 下の「Assets」から `Hikidana-0.2.1-win-x64.zip` をダウンロードし、好きな場所に展開します。
2. 展開したフォルダーの `Hikidana.exe` を開きます（インストールは要りません。Windows 11 / 10 の 64 ビット版で動きます）。

- 初めて開くときに「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください（このアプリには署名をしていないためです）。
- 棚の中身と設定は `%LOCALAPPDATA%\Hikidana` にあります。
