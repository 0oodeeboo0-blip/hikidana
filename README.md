# Hikidana

コピーしたものやスクリーンショットを、画面の端の「引き棚」にしまっておける Windows 用のアプリです（開発中）。

- **確実に貼れる**: スクリーンショットは画像のまま、OneNote・Word・Teams・ブラウザーにそのまま貼れる
- **邪魔をしない**: ふだんは画面の端に細い取っ手があるだけ。開いても作業中のアプリからフォーカスを奪わない
- **今どきの見た目**: Windows 11 になじむデザイン、ライトとダーク

## 状況

開発中です（段階 2: 棚の画面）。計画と決まったことは [docs/plan.md](docs/plan.md) にあります。

## 試し方（開発中の版）

1. このリポジトリの「Actions」を開き、いちばん上の緑のチェックが付いた「CI」をクリックします。
2. 下の方の「Artifacts」にある **Hikidana-win-x64** をクリックすると、zip がダウンロードされます（GitHub へのログインが要ります）。
3. zip を展開して、中の **Hikidana.exe** をダブルクリックします。インストールは要りません。
   「Windows によって PC が保護されました」と出たときは、「詳細情報」→「実行」を押します（署名をしていないため）。
4. 画面の右端の真ん中に、細い線（取っ手）が出ます。マウスを乗せるとつまみになり、クリックすると棚が開きます。
   **Win+Alt+V** でも開けます（文字で探して ↑↓ で選び、Enter で貼り付け、Esc で閉じる。キーボードだけで使えます）。
   棚の外をどこかクリックするか、Esc を押すと閉じます。
5. スクリーンショット（Win+Shift+S）を撮ったり、何かをコピーしたりすると、棚に入ります。
   ChatGPT や Claude の入力欄をクリックしておいてから棚のカードをクリックすると、そこに貼り付けます。
   - Shift を押しながらクリックすると、書式なしで（画像はファイルとして）貼り付けます。
   - **Ctrl を押しながら**カードをクリックすると、選べます（選んだ順に番号が付きます）。下の「まとめて貼り付け」で、
     その順に続けて貼り付けます（スクショを何枚か ChatGPT へ、など）。選んでいる間は、クリックで選ぶ・外す。
   - スクショやコピーしたものが棚に入ると、取っ手からカメラなどの印が少し出て知らせます。
   - カードを右クリックすると、貼り付け方を選んだり、名前を付けて保存したりできます。
   - カードにマウスを乗せると、右上に「コピーだけ」「消す」「ピン留め」のボタンが出ます。
   - カードは、ChatGPT や Claude の入力欄、エクスプローラーなどへドラッグしても渡せます（画像は PNG ファイルとして）。
   - 反対に、ファイル・画像・テキストを取っ手か棚へドラッグすると、棚にしまえます。
   - 上の検索の欄をクリックすると、文字で探せます（↑↓ で選んで Enter で貼り付け、Esc でやめる）。その下の丸いボタンで種類を絞れます。
   - 取っ手はドラッグすると、端に沿って動かせます。
   - 棚の右上の「…」かタスクトレイのメニューで「マウスを乗せるだけで開く」にすると、取っ手にマウスを乗せるだけで開き、離れると閉じます。
   - 棚の右上の「…」の「ピン留め以外のスクリーンショットを消す」「ピン留め以外をすべて消す」で、まとめて片付けられます
     （ピン留めしたものは残ります。消したあと少しの間は、知らせの「元に戻す」で戻せます）。
6. 棚の右上の「…」かタスクトレイのメニューの「設定」で、設定の画面が開きます。変えるとすぐ棚に反映され、次に起動したときも残ります。
   - **棚の位置**: 画面の図の端の近くをクリックするか、「右」「左」「上」「下」のボタンで、棚を出す端を選べます。
     モニターが 2 つ以上あるときは、どの画面に出すかも選べます。「真ん中に戻す」で取っ手を端の真ん中に戻せます。
   - **開き方**: 取っ手をクリックしたときに開くか、マウスを乗せたときに開くか。ショートカットキー（Win+Alt+V など・使わない）。
     貼り付けたら棚を閉じるか。
   - **見た目**: Windows に合わせる・ライト・ダーク。棚に入ったら取っ手で知らせるか。
   - **記録**: しまっておく数（ピン留めは数えません）、古いものを自動で消す（例: 7 日たったスクリーンショット）、
     貼り付けたものを上へ動かすか、記録を止めるか、棚の片付け（スクリーンショットを消す・すべて消す）。
   - **起動**: Windows にサインインしたら、自動で Hikidana を動かすか。
7. タスクトレイ（画面右下の「^」の中）にもアイコンがあり、クリックで棚が開き、右クリックで設定、記録の一時停止、終了ができます。
   いつも見えるようにするには、Windows の「設定」→「個人用設定」→「タスクバー」→「その他のシステム トレイ アイコン」で Hikidana をオンにします。
8. 終わるときは、タスクトレイのアイコンを右クリック →「Hikidana を終了」（棚の右上の「…」からも終了できます）。

しまったものと設定は `%LOCALAPPDATA%\Hikidana` にあります。うまく動かないときは、その中の `logs` フォルダーの記録（ログ）を見ると、
何が起きたかが分かります（コピーした中身は書きません）。
