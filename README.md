# Hikidana

コピーしたものやスクリーンショットを、画面の端の「引き棚」にしまっておける Windows 用のアプリです（開発中）。

- **確実に貼れる**: スクリーンショットは画像のまま、OneNote・Word・Teams・ブラウザーにそのまま貼れる
- **邪魔をしない**: ふだんは画面の端に細い取っ手があるだけ。開いても作業中のアプリからフォーカスを奪わない
- **今どきの見た目**: Windows 11 になじむデザイン、ライトとダーク

## 状況

開発中です（段階 1: クリップボードの仕組みと、仮の棚）。計画と決まったことは [docs/plan.md](docs/plan.md) にあります。

## 試し方（開発中の版）

1. このリポジトリの「Actions」を開き、いちばん上の緑のチェックが付いた「CI」をクリックします。
2. 下の方の「Artifacts」にある **Hikidana-win-x64** をクリックすると、zip がダウンロードされます（GitHub へのログインが要ります）。
3. zip を展開して、中の **Hikidana.exe** をダブルクリックします。インストールは要りません。
   「Windows によって PC が保護されました」と出たときは、「詳細情報」→「実行」を押します（署名をしていないため）。
4. 画面の右端の真ん中に、細い線（取っ手）が出ます。マウスを乗せるとつまみになり、クリックすると棚が開きます。
5. スクリーンショット（Win+Shift+S）を撮ったり、何かをコピーしたりすると、棚に入ります。
   ChatGPT や Claude の入力欄をクリックしておいてから棚のカードをクリックすると、そこに貼り付けます。
   - Shift を押しながらクリックすると、書式なしで（画像はファイルとして）貼り付けます。
   - カードにマウスを乗せると、右上に「コピーだけ」「消す」「ピン留め」のボタンが出ます。
   - 取っ手はドラッグすると、端に沿って動かせます。
6. 終わるときは、棚の右上の「…」→「Hikidana を終了」を押します。

しまったものと設定は `%LOCALAPPDATA%\Hikidana` にあります。うまく動かないときは、その中の `logs` フォルダーの記録（ログ）を見ると、
何が起きたかが分かります（コピーした中身は書きません）。
