# Hikidana 開発計画

最終更新: 2026-11-07

## 目指すもの

コピーしたものやスクリーンショットを画面の端の「引き棚」にしまっておき、いつでも取り出して貼り付けられる Windows 用のアプリ。
[Edge-Drop](https://github.com/Deepender25/Edge-Drop) と同じ使い方で、次の 3 つを実現する。

1. **確実に貼れる**: スクリーンショットは画像のまま、どのアプリにも貼れる（ChatGPT・Claude のアプリ、ブラウザー、Word・Teams・OneNote など）。
   貼れなかったときは黙らずに知らせ、別のものを貼ってしまうことはない。
2. **邪魔をしない**: ふだんは画面の端に細い取っ手が見えるだけ。開いても作業中のアプリからフォーカスを奪わない。
   全画面のゲームや発表の間は出てこない。
3. **今どきの見た目**: Windows 11 になじむデザイン、ライトとダーク、高解像度の画面でもくっきり、なめらかな動き。

## 決まっていること

| 項目 | 決定 |
|---|---|
| 名前 | Hikidana（引き棚） |
| 公開 | GitHub の非公開リポジトリ。配布は GitHub の Releases（インストール不要の zip） |
| 対象の Windows | Windows 11（64 ビット）。Windows 10 でも動くようにはするが、角の丸みやすりガラスは簡略になり、確かめるのは Windows 11 だけ |
| 画面の言語 | 日本語 |
| 技術 | C# / .NET 10、WPF（Windows 11 の Fluent デザイン）。クリップボード・キー入力・ウインドウは Win32 API を直接使う（PowerShell は使わない） |
| 作り方 | Claude がコードを書いて GitHub に置き、GitHub Actions の Windows でビルド・テスト・画面写真の撮影まで行う |
| Edge-Drop との関係 | 使い方と考え方を参考にする。コードは使わない |

## Edge-Drop の問題と Hikidana での対処

Edge-Drop v0.4.0（2026-11-05 時点の main）のコードで確かめた。

| Edge-Drop の問題 | Hikidana での対処 |
|---|---|
| スクリーンショットを貼るとき、画像と一緒に一時ファイルの参照（エクスプローラーでいう「ファイルのコピー」）も渡す（`electron/main/ipc.ts` の `writeImageWithNamedFile`）。OneNote はファイルの方を読みにいき、見つからずに「指定されたファイルが見つかりません」になる。ChatGPT や Discord では「ファイルが空です」になることがある（Edge-Drop の Issue #44）。ほかのチャットやブラウザーでも、添付ファイル扱いや 2 枚になる | 画像は画像の形（PNG と DIB）だけで渡す。Win+Shift+S で撮った直後と同じ中身にする。ファイルとして渡すのは、貼り付け先がエクスプローラーかデスクトップのときと、自分で「ファイルとして貼り付け」を選んだときだけ |
| クリップボードへの書き込みとキー入力を、裏で動かし続ける PowerShell に頼っている（`electron/main/powershell.ts`）。書き込みに失敗しても成功扱いになり、直前の別の内容が貼られることがある。時間切れのあと 2〜3 秒遅れて貼られることもある | Win32 API を直接呼ぶ。書き込んだ中身を読み戻して確かめてから Ctrl+V を送る。確かめられなければ貼らずに知らせる |
| Ctrl+V を SendKeys で送る。押したままのキーと混ざって別の操作になることがある（Ctrl+Alt+V など）。管理者として動いているアプリには届かず、届かなかったことも分からない | SendInput で送り、Shift・Ctrl・Alt・Windows キーが離されるのを待ってから送る。相手が管理者として動いているときは自動では貼らず、「コピーは済んでいるので Ctrl+V を押してください」と知らせる |
| スクリーンショットかどうかを「テキストの無い画像だから」と推し量っている | クリップボードに書いたアプリ（Snipping Tool など）を見て見分ける |
| 取り込むときに一部の形しか残さない | 元のクリップボードの形を大きさの上限つきで残しておき、そのまま戻す（Excel の表や Word の書式が崩れない） |

## 機能

### 最初の版（v1.0）

- **棚**: 画面の端の取っ手に触れると出る。ショートカット（Win+Alt+V。変えられる）でも開く。
  マウスが離れるとしまう。「開いたままにする」もできる。
- **棚の位置**: 右・左・上・下の端から選べる（既定は右）。取っ手は端に沿ってドラッグで好きな高さ（上下なら横の位置）へ動かせる。
  モニターが複数あるときは、どのモニターに出すか（マウスのあるモニター・メイン・決まったモニター）も選べる。
- **しまえるもの**: テキスト、書式つきテキスト（Word・Web など）、コード、URL、画像、スクリーンショット、
  ファイルとフォルダー（元の場所を指す）、色、Excel の表。
- **貼り付け**: クリックで、直前まで使っていたアプリに貼る。右クリックで「書式なしで」「ファイルとして」「コピーだけ」。
  ドラッグで好きな場所へ。貼った先のアプリの名前を知らせる。
- **取っ手へ運ぶ**: ファイル・画像・テキストを取っ手までドラッグすると、棚にしまえる。
- **整理**: ピン留め、検索、種類での絞り込み、削除（すぐなら元に戻せる）、プレビュー（Space）、名前を付けて保存。
- **キーボード**: ↑↓ で選ぶ、Enter で貼る、Shift+Enter で書式なし、Delete で削除、Esc で閉じる、文字を打つと検索。
- **記録しないもの**: パスワード管理アプリが「記録しないで」と印を付けたもの、記録しないアプリに指定したもの、一時停止中にコピーしたもの。
- **履歴**: 件数（100〜1000。既定 300）と期間の上限。ピン留めは消えない。同じものをもう一度コピーしたら、新しく足さずに上へ上げる。
  保存先は `%LOCALAPPDATA%\Hikidana`。
- **その他**: タスクトレイ（一時停止・設定・終了）、Windows の起動時に開始、ライト・ダーク（Windows に合わせる）、
  表示倍率 100〜200% とマルチモニター、全画面のアプリの間は取っ手を隠す、新しい版のお知らせ。

### その後の版

スタック（いくつかを 1 枚にまとめる）、複数を選んで続けて貼る、履歴の暗号化（Windows の DPAPI）、英語版、署名とインストーラー。

### 入れないもの（今のところ）

クラウドでの同期（ほかの PC との共有）。

## 貼り付けの仕組み

貼り付け先と、しまってあるものの種類で、クリップボードに置く形を決める。

| しまってあるもの | ふつうのアプリ | エクスプローラー・デスクトップ |
|---|---|---|
| スクリーンショット・画像 | PNG と DIB（画像だけ） | 名前付きの PNG ファイル |
| テキスト | テキスト（書式つきなら HTML・RTF も） | テキストのまま（エクスプローラーには貼れない） |
| 表（Excel） | 取り込んだときの形のまま | 同左 |
| ファイル | ファイル（元の場所） | ファイル（元の場所） |

手順:

1. 棚を開く前に前面にあったアプリを覚えておく（棚はフォーカスを奪わない）。
2. クリップボードに書き、読み戻して確かめる。ほかのアプリが使っていたら、少し待ってやり直す。
3. 押したままのキーが離れるのを待つ。
4. Ctrl+V を送る。
5. 貼った先の名前を知らせる。

貼れないとき（相手が管理者として動いている、全画面のゲームなど）は、コピーまでにして知らせる。

## 見た目

デザイン案は claude.ai の Artifact「Hikidana デザイン案」（動く見本つき）。
案A「なじむ」と案B「和の棚」から、**案A** に決まった（2026-11-07）。

- Windows 11 の標準のデザイン（Fluent）。棚はすりガラス（Acrylic）、角の丸みは 12px、カードは 8px。
- 色は Windows のアクセント色に合わせる（既定の青なら、ライト #005FB8・ダーク #60CDFF）。ライトとダークは Windows の設定に合わせる。
- 文字は Segoe UI Variable と Yu Gothic UI。本文 13.5px、行の高さ 1.6。アイコンは線の細いもの（Segoe Fluent Icons に合わせる）。
- 棚の幅は 360px（表示倍率 100% のとき）。画面の端から 12px 離して出す。左右の端なら上下いっぱい、
  上下の端なら取っ手の近くに高さ 7 割ほどで出す（カードの並びはどの位置でも同じ）。下の端はタスクバーの上に置く。
- 取っ手は、ふだんは幅 5px の細い棒。近づくと色が付き、触れると 28×96px のつまみになって、0.2 秒で棚が出る。
- お知らせ（貼り付けた・コピーした・貼れなかった）は棚の下に出し、数秒で消す。

アプリのアイコンは、藍色の角丸の四角に、引き出した棚の白い線画。

## 品質の確かめ方

- 変更のたびに GitHub Actions の Windows で:
  - **クリップボードのテスト**: Snipping Tool と同じ形の画像をクリップボードに置き、Hikidana が取り込み、貼り付け用に書き戻した中身を調べる
    （PNG と DIB があり、ファイルの参照が無いこと。画素が元と同じこと）。
  - **実際に貼るテスト**: 本物のキー操作で貼り、届いた中身を確かめる。
    - ブラウザー（Edge）: ChatGPT や Claude と同じ受け取り方（貼り付けられたファイルを読む）をするテスト用のページで、
      画像が 1 枚だけ届くこと、中身が空でないこと、大きさが元と同じことを確かめる。ChatGPT と Claude のアプリも中身は同じ仕組み（Chromium）。
    - メモ帳（テキスト）、テスト用のアプリ（書式つきテキストと画像）。
  - **画面写真**: ライト・ダーク、表示倍率 100・150・200%、空・一時停止・キーボードなどの状態。
- いちばんよく使う貼り付け先は ChatGPT と Claude（アプリとブラウザー）。CI に無いこれらのアプリと Word・Teams・OneNote などは、
  段階の終わりに手元で確かめてもらう（確かめることの一覧を付ける）。

## 進め方

| 段階 | 内容 |
|---|---|
| 0. 準備 | リポジトリと自動ビルド、デザイン案、この計画 |
| 1. クリップボードの仕組み | 取り込み・保存・書き戻し・貼り付け（キーの送信）と、その自動テスト。仮の画面で、ChatGPT と Claude のアプリにスクリーンショットが貼れることを確かめてもらう |
| 2. 棚の画面 | 取っ手、棚、カード、検索と絞り込み、ピン留め、ドラッグ、タスクトレイ、ライト・ダーク |
| 3. 普段使いできる版 | 設定、ショートカット、記録しないアプリ、プレビュー、自動起動、配布と新しい版のお知らせ |
| 4. その後の版 | スタックなど |

それぞれの段階の終わりに動くものを確かめてもらってから、次へ進む。

### 進み具合

- **段階 0（完了。2026-11-07）**: 計画、デザイン案（案A に決まった）、リポジトリと自動ビルド
  （Linux で仕組みのテスト、Windows でアプリの発行・起動テスト・ライトとダークの画面写真）。
  いちばんよく使う貼り付け先は ChatGPT と Claude のアプリだと聞いた（OneNote は使っていない。OneNote で貼れない様子は動画で見た）。
  棚を右以外の端にも置きたいと聞き、右・左・上・下から選べるようにした。
- **段階 1（完了。2026-11-07）**: クリップボードの仕組みと、仮の棚。
  - 取り込み（見張り、記録しない印やアプリの尊重、自分が書いたものは取り込まない）、保存、書き戻しと読み戻しでの確認、
    押したままのキーを待ってからの Ctrl+V、管理者のアプリや閉じたウインドウではコピーまでにして知らせる、ができた。
  - CI の Windows で、本物のクリップボードとキー操作で Edge のテストのページ（ChatGPT や Claude と同じ Chromium）とメモ帳に貼るテストが通る。
    スクリーンショットは「image.png」として届く（Win+Shift+S の直後と同じ）。発行したアプリの棚のカードをクリックして貼るテストもある。
  - 仮の棚: 端の取っ手（右・左・上・下、ドラッグで移動）、カード（画像・テキスト・コード・表・リンク・色・ファイル）、
    クリックで貼り付け（Shift で書式なし・ファイルとして）、コピー・ピン留め・削除（元に戻せる）、記録の一時停止、知らせ。
  - 利用者の手元で、取っ手から棚が開く・スクリーンショットが棚に入る・ChatGPT と Claude のアプリに画像として貼れる、の 4 つを確かめてもらった。
- **段階 2（作っているところ）**: 棚の画面。
  - 利用者から「ドラッグでも貼れるようになる？」と聞かれたので、ドラッグを最初に作る。
    カードをほかのアプリへドラッグして渡す（画像は名前の付いた PNG ファイル、テキストは書式つき、リンクは URL も、ファイルはそのファイル）。
    ほかのアプリから取っ手や棚へ落としたものをしまう（ブラウザーの画像のように中身だけ渡されるものは PNG にする）。
  - カードの右クリックのメニュー（貼り付け・書式なし／ファイルとして・コピーだけ・ピン留め・名前を付けて保存・消す）。
  - 検索と絞り込み（すべて・画像・テキスト・リンク・ファイル・ピン留め）。検索の欄をクリックしたときだけ棚がキーボードを受け取り、
    ↑↓ で選んで Enter で貼り付け、Esc で元のアプリに戻る。貼り付け先は、その前に使っていたアプリ。
  - タスクトレイ（クリックで棚、右クリックで一時停止・保存先・記録・終了）。
  - すりガラス（ACCENT_ENABLE_ACRYLICBLURBEHIND。棚は前面にならないので、前面のときだけ効く DWM の背景は使わない）と、
    端から 0.2 秒で滑り出る動き。Windows の「透明効果」「アニメーション効果」が切ってあれば使わない。
    CI の Windows は仮想マシンで、ぼかしが写らないので、見た目は利用者の PC で確かめてもらう。
  - 利用者の PC で、ドラッグ（棚から ChatGPT・Claude へ、ほかのアプリから取っ手へ）とすりガラスの見た目を確かめてもらった。
  - 「…」のメニューと小さなボタンの説明の日本語が四角（□）になっていた。ボタンの記号のフォントを受け継いでいたため。直した。
  - 利用者の希望で「マウスを乗せるだけで開く」を設定に加えた（初めはクリックで開く）。「…」とタスクトレイのメニューで切り替える。
    乗せるだけで開くときは、棚からマウスが離れると閉じる（メニュー・検索・ドラッグの間と、開いたままにしているときは閉じない）。
  - 利用者の希望（「位置も設定から出来るようにして」）で、段階 3 の予定だった設定の画面を先に作った。
    「…」とタスクトレイの「設定」で開く。Windows 11 の設定アプリと同じ作り（見出しとカード、Mica、トグルスイッチ）。
    変えたらすぐ棚に反映して保存する（OK のボタンは無い）。
    - 棚の位置: 画面の図（いまの画面の形・タスクバー・棚と取っ手を縮めて描く）の端の近くをクリックするか、右・左・上・下のボタン。
      モニターが 2 つ以上なら出す画面（メインを選んだら「メイン」として覚える）。取っ手を真ん中に戻す。
      別の画面へ動かしたとき、表示倍率が違うと WPF がウインドウの大きさを変えるので、DpiChanged で置き直す。
    - 開き方（クリック・マウスを乗せる）、貼り付けたら閉じる、色（Windows に合わせる・ライト・ダーク。その場で切り替わる）、
      しまっておく数（減らして消えるものがあれば、確かめてから古いものを消す）、貼り付けたものを上へ、記録を止める。
    - Windows にサインインしたら起動: HKCU の Run に exe の場所を書く。Windows の「スタートアップ アプリ」で切られていれば「オフ」と見せ、
      オンにし直したら切った印も消す。起動するたびに、書いてある場所が違えば（exe を動かした・新しい版にした）いまの場所に直す。
      見本（--demo）のときは本物の設定に触れない。
    - CI では、UI オートメーションで設定の画面の「左」を押して取っ手が左の端へ動くこと、設定のファイルに残ることを確かめる。
  - 利用者の希望（「ピン止め以外のスクショ、一気に削除機能あるといいかも」）で、まとめて消す機能を足した。
    「…」の「ピン留め以外のスクリーンショットを消す」「ピン留め以外をすべて消す」（何件消えるかをメニューに出す）。
    Windows の Win+V の「すべてクリア」と同じく確かめずに消し、そのかわり知らせの「元に戻す」で戻せる（ごみ箱のフォルダーに動かしておき、
    次に起動したときに空にする）。設定の画面の「記録」の「棚を片付ける」からも消せる（こちらは件数を見せて確かめる）。
  - 利用者の希望で、閉じ方を足した: 棚の外をクリック（作業中のアプリの中でも）と Esc。棚はフォーカスを取らないので、
    作業中のアプリをクリックしても前面が変わらず、これまでは閉じなかった。棚が開いている間だけ WH_MOUSE_LL と WH_KEYBOARD_LL を付け、
    押してから離すまで外なら閉じる（クリックはそのままアプリへ届ける）。Esc はほかのアプリが前面のときだけ取り、アプリへは渡さない。
    開いたままにしているとき・メニューやダイアログを開いているとき・ドラッグ中は閉じない。タスクバーのクリックは数えない。
  - 利用者が選んだ改善（1・2・3・5・6）:
    - ショートカット（初めは Win+Alt+V。RegisterHotKey）。押すと棚が開いてキーボードを受け取る（検索・↑↓・Enter・Esc）。
      貼り付け先は押したときのアプリ。ほかのアプリが使っていて登録できないときは知らせて、設定で別のキーを選べる。
    - まとめて貼る: Ctrl+クリックで選び（選んだ順の番号）、下のバーの「まとめて貼り付け」で 1 つずつクリップボードに置いて Ctrl+V。
      貼り付け先が読み終えるよう、画像のあとは 0.9 秒、テキストのあとは 0.35 秒あける（CF_HDROP は使わない決まりのまま）。
    - 古いものを自動で片付け: 最後に使ってから N 日（初めは「消さない」）。スクリーンショットだけか、ピン留め以外すべてか。10 分ごとに片付ける。
    - 棚に入った合図: 取っ手のつまみを 1.5 秒ほどアクセント色で出して、種類の記号（スクショはカメラ）を見せる。設定で切れる。
    - 新しい版のお知らせ: リポジトリは公開だった（非公開と思い込んで相談してしまい、訂正した）。版（Directory.Build.props）を上げて
      main に push すると、CI が Releases に zip と SHA-256 を置く。アプリは 30 秒後と 6 時間ごとに releases/latest を確かめ、
      新しければ知らせとタスクトレイと設定に出す。「入れ替える」で zip を落としてチェックサムを確かめ、動いている exe の名前を
      「.old」に変えてから新しい exe を置き、--updated --wait で起動し直す（前の版が終わるのを待つ。.old は次の起動で消す）。
      0.2.0 を最初の版として出す。
