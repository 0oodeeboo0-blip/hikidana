## Hikidana 0.3.0

コピーしたものやスクリーンショットを、画面の端の「引き棚」にしまっておける Windows 用のアプリです。

### 0.3.0 で増えた設定

設定の画面を、Windows 11 の設定アプリと同じく「左に項目、右にそのページ」の作りにしました
（位置と大きさ・動作・見た目・記録と片付け・このアプリについて）。

- **取っ手の大きさ**（小・中・大）: 大きくすると、マウスで当てやすくなります。
- **棚の長さ**（小・中・大）: 小さくすると、取っ手の横に短い棚が出ます。
- **全画面のときは取っ手を隠す**: ゲームや動画を全画面で見ている間は、取っ手を隠して、マウスが端に行っても開かないようにします（初めからオン）。
- **棚の文字の大きさ**（小・標準・大）: 棚の中身をまとめて大きく・小さくします。
- **知らせの印**（しまったものの種類・チェック・印なし）: 棚に入ったときに取っ手から出る印。「試す」で光らせて見られます。
- **効果音**: 棚を開け閉めしたときと、貼り付けたときに、小さな音を鳴らします（初めはオフ）。
- **起動したときに消す**: Hikidana が起動するたびに、ピン留め以外（またはスクリーンショットだけ）を消します。
- **古いものを自動で消す**に「1 時間」「6 時間」を足しました。
- 「このアプリについて」に GitHub のページを開くボタンを足しました。

0.2.0 か 0.2.1 を使っていれば、アプリが新しい版を知らせるので「入れ替える」を押すだけです（棚の中身と設定はそのままです）。

## 使い方

1. **[Hikidana-0.3.0-win-x64.zip](https://github.com/0oodeeboo0-blip/hikidana/releases/download/v0.3.0/Hikidana-0.3.0-win-x64.zip)** をダウンロードし（下の「Assets」にもあります）、好きな場所に展開します。
   「Source code」はプログラムの元のファイルなので、使いません。
2. 展開したフォルダーの `Hikidana.exe` を開きます（インストールは要りません。Windows 11 / 10 の 64 ビット版で動きます）。

- ブラウザーが「一般的にダウンロードされていません」などと出して止めたときは、ダウンロードの一覧でそのファイルの「…」から「保存」を選び、
  続けて出る画面で「詳細表示」→「保持する」を押してください（出したばかりの版は、ダウンロードした人がまだ少ないため、こう出ることがあります）。
- 初めて開くときに「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください（このアプリには署名をしていないためです）。
- 棚の中身と設定は `%LOCALAPPDATA%\Hikidana` にあります。
