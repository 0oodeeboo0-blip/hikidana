## Hikidana 0.3.2

コピーしたものやスクリーンショットを、画面の端の「引き棚」にしまっておける Windows 用のアプリです。

### 0.3.2 での直し

- 取っ手をクリックして（またはマウスを乗せて）開いた棚が、棚の外をクリックしても閉じないことがあったのを直しました。
  - 棚のメニュー（右クリックや「…」）を使ったあとに、「メニューが開いている」と思い込んだままになることがありました。
    いまは、本当に開いているメニューがあるかを、そのたびに確かめます。棚を閉じるときは、開いているメニューも閉じます。
  - 外のクリックの見張りを、専用の流れ（スレッド）で動かすようにしました。アプリが忙しいときに Windows が見張りを黙って外してしまうことがあったためです。
- マウスを乗せて開いた棚が、マウスを離しても閉じないことがあったのも、同じ原因でした（一緒に直りました）。

## 使い方

1. **[Hikidana-0.3.2-win-x64.zip](https://github.com/0oodeeboo0-blip/hikidana/releases/download/v0.3.2/Hikidana-0.3.2-win-x64.zip)** をダウンロードし（下の「Assets」にもあります）、好きな場所に展開します。
   「Source code」はプログラムの元のファイルなので、使いません。
2. 展開したフォルダーの `Hikidana.exe` を開きます（インストールは要りません。Windows 11 / 10 の 64 ビット版で動きます）。

- 0.2.0 からあとの版を使っていれば、アプリが新しい版を知らせるので「入れ替える」を押すだけです（棚の中身と設定はそのままです）。
- ブラウザーが「一般的にダウンロードされていません」などと出して止めたときは、ダウンロードの一覧でそのファイルの「…」から「保存」を選び、
  続けて出る画面で「詳細表示」→「保持する」を押してください（出したばかりの版は、ダウンロードした人がまだ少ないため、こう出ることがあります）。
- 初めて開くときに「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください（このアプリには署名をしていないためです）。
- 棚の中身と設定は `%LOCALAPPDATA%\Hikidana` にあります。
